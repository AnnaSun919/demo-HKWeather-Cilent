# HK Weather Client

A React frontend that displays live weather data from the Hong Kong Observatory, powered by the [hk-weather-server](../server).

## Prerequisites

Make sure the server is running locally before starting the client:

Server: https://github.com/AnnaSun919/demo-HKWeather


```bash
# in the server folder
npm start
```

Server runs at `http://localhost:3000`.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

App runs at `http://localhost:5173`.
